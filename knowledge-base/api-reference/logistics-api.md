# Logistics API Reference

## Description
Obtain logistic resource information -- warehouses, delivery options, shipping providers.

## Endpoint Count: 5

## Endpoints

| # | Method | Endpoint | Doc |
|---|--------|----------|-----|
| 1 | GET | Get Warehouse List | [Link](https://partner.tiktokshop.com/docv2/page/get-warehouse-list-202309) |
| 2 | GET | Get Global Seller Warehouse | [Link](https://partner.tiktokshop.com/docv2/page/get-global-seller-warehouse-202309) |
| 3 | GET | Get Warehouse Delivery Options | [Link](https://partner.tiktokshop.com/docv2/page/get-warehouse-delivery-options-202309) |
| 4 | GET | Get Shipping Providers | [Link](https://partner.tiktokshop.com/docv2/page/get-shipping-providers-202309) |
| 5 | GET | Get Available Shipping Template | [Link](https://partner.tiktokshop.com/docv2/page/get-available-shipping-template-202510) |

## Key Concepts

- One seller can have multiple warehouses per shop
- Delivery options include shipping type (Platform vs Seller) and shipping services
- US shipping services example: "USPS Ground", "DHL eCommerce SM parcel"

# Products API Reference

## Description
Access product categories, upload images/videos/certifications, create/edit products, update inventory/prices. Includes Global Product APIs for cross-border e-commerce.

## Key Policies

- New sellers: 100 product uploads/day during probation
- Post-probation: 1,000 uploads/day
- Brand authorization required for certain brands
- Product statuses: Draft, Pending, Failed, Activate, Seller_deactivated, Platform_deactivated, Freeze, Deleted

# Seller API Reference

## Description
Exclusively for cross-border operations. Retrieve shop status and Global Product feature eligibility.

## Base URL
```
https://open-api.tiktokglobalshop.com/seller/{version}/...
```

## Endpoints

| # | Method | Endpoint | Description |
|---|--------|----------|-------------|
| 1 | GET | Get Active Shops | Retrieve seller's active shop information |
| 2 | GET | Get Seller Permissions | Check Global Product feature eligibility |

# Customer Engagement API Reference

## Description
Send targeted marketing messages to past buyers via TikTok IM. Promote products, coupons, and drive conversions.

## Endpoint Count: 6

## Endpoints

| # | Method | Endpoint | Doc |
|---|--------|----------|-----|
| 1 | GET | Get Message Templates | [Link](https://partner.tiktokshop.com/docv2/page/get-message-templates-202412) |
| 2 | POST | Create Engagement Task | [Link](https://partner.tiktokshop.com/docv2/page/create-engagement-task-202412) |
| 3 | POST | Send Engagement Message | [Link](https://partner.tiktokshop.com/docv2/page/send-engagement-message-202412) |
| 4 | POST | Get Task Performances | [Link](https://partner.tiktokshop.com/docv2/page/get-task-performances-202412) |

| 6 | GET | Get Feature Permissions | [Link](https://partner.tiktokshop.com/docv2/page/get-feature-permissions-202502) |

## Key Limitations

- **US local sellers only**
- Recipients must have placed at least 1 order in past 365 days
- Max 100 active tasks simultaneously
- 1 message per calendar week per buyer (shared across all channels)
- Performance data available 48 hours after execution

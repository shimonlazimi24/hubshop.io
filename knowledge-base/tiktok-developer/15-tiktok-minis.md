# TikTok Developer - TikTok Minis

## Overview

TikTok Minis is a **mobile webpage-based product framework** that provides partners with an enriched web app ecosystem within the TikTok app. It allows third-party services to integrate mini applications directly inside TikTok, enabling users to access external content seamlessly without leaving the app.

## Architecture

- Web-based architecture (HTML/CSS/JS)
- Supports HTML mini games alongside native mobile implementations
- Runs within TikTok's embedded webview environment

## Key Capabilities

- **Accelerated loading** and performance optimization
- **Web content integration** without complex technical requirements
- **Transaction handling** and advertising configurations
- **Content protection** mechanisms
- **User reporting** and feedback systems
- **OAuth authentication** for secure user access
- **Webhook integration** for event-driven interactions

## Available APIs Within Minis

### Core Integration APIs

- Content Posting API (direct post and upload)
- Data Portability API (user data requests)
- Display API (content querying and user information)
- OAuth (secure authentication)
- Webhooks (event notifications)

### Mini-Specific SDKs

- Login and authorization tools
- Payment processing systems
- Device and network utilities
- Media handling capabilities
- In-app advertising modules
- In-app purchase modules

## Development & Deployment Process

### Phase 1: Preparation

1. Register apps on the Developer Portal
2. Configure app settings
3. Contact TikTok to access TikTok Minis configurations

### Phase 2: Development

1. Develop the mini app using web technologies
2. Complete local testing
3. Integrate APIs
4. Debug the application

### Phase 3: Publication

1. Upload code assets
2. Import production configurations
3. Submit for review

## Platform Support

- Mobile SDK support for iOS and Android
- Server-side APIs for backend integration
